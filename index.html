Pronunciation Reference

Read these important pronunciation rules before completing Activities 3 and 4.

H is silent.
Example: hola.
U is silent in gue / gui.
The gu represents the hard G sound.
U is silent in que / qui.
The qu represents the K sound.
ch, ll, rr each represent one sound in this activity.
